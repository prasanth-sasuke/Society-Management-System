# Environment variables

## Where each value lives

| File / place | Used by | Committed? |
|---|---|---|
| `.env` (repo root; `server/.env` is a symlink to it) | Local API, Prisma, seed, verify scripts | **No** (gitignored) — template: `.env.example` |
| `.env.cloud` (repo root) | Scripts that talk to Neon: `verify:cloud`, `backup:cloud`, `prisma:seed:cloud`, `migrate:cloud` | **No** (gitignored) — template: `.env.cloud.example` |
| Render dashboard → Environment | Production API | Never in git; `render.yaml` only lists the names |
| `web/.env.development`, `web/.env` | Vite (web app build) | `.env.development` is committed and contains no secrets |
| `mobile/.env` | Expo during local development | **No** — template: `mobile/.env.example` |
| `mobile/eas.json` → `build.*.env` | EAS cloud builds | Yes (public URL only) |

`VITE_*` and `EXPO_PUBLIC_*` values are compiled into the JavaScript that ships to
browsers and phones. Anyone can read them, so they must never contain secrets.

## Server (Node.js API)

| Variable | Required | Default | Description |
|---|---|---|---|
| `DATABASE_URL` | Yes | — | PostgreSQL URL used by the running app. Local: `postgresql://society_app:<password>@localhost:5432/society_management_dev`. Production: Neon **pooled** URL with `sslmode=require`. |
| `DIRECT_URL` | Yes | — | Unpooled URL for Prisma migrations. Local: same as `DATABASE_URL`. Production: Neon **direct** URL. |
| `JWT_SECRET` | Yes | — | Signs login tokens (HS256). Long random string; the server refuses to start without it. Changing it signs everyone out. |
| `JWT_EXPIRES_IN` | No | `12h` | Login token lifetime (`12h`, `7d`, …). |
| `NODE_ENV` | No | `development` | `production` enables HSTS, request logging, serving `web/dist`, and listening on `0.0.0.0`. |
| `PORT` | No | `3001` | HTTP port. Render sets it automatically. |
| `LISTEN_HOST` | No | `127.0.0.1` (dev), `0.0.0.0` (production) | Set `0.0.0.0` locally to let a phone on the Wi-Fi reach the API. |
| `CORS_ORIGIN` | No | none | Comma-separated browser origins allowed to call the API from another origin (local Vite: `http://localhost:5173,http://127.0.0.1:5173`). Not needed in production, where the web app is served by the API itself. The Android app does not need CORS. |
| `LOG_REQUESTS` | No | off (on in production) | `1` prints one line per API request locally (`GET /api/bills 200 12ms`). |
| `SOCIETY_UTC_OFFSET` | No | `+05:30` | Time zone used for "today", due dates and date labels. |
| `SUPERADMIN_EMAIL` | Seed only | — | First login created by `npm run prisma:seed` / `prisma:seed:cloud`. |
| `SUPERADMIN_PASSWORD` | Seed only | — | Its password (stored bcrypt-hashed). Also used by `npm run verify:api`. |
| `SEED_RESET` | No | — | `yes` lets the seed erase a database that already has data. |
| `PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` | No | — | Convenience for `psql` / local scripts; the app itself only reads `DATABASE_URL`. |

Production values in Render: `NODE_ENV=production`, `NODE_VERSION=22`, `JWT_EXPIRES_IN=12h`,
`JWT_SECRET` (generated by Render), `DATABASE_URL`, `DIRECT_URL`.

## Maintenance scripts

| Variable | Used by | Description |
|---|---|---|
| `BACKUP_KEEP` | `npm run backup:cloud` | How many dumps to keep in `dumps/` (default 14). |
| `FORCE` | `npm run migrate:cloud` | `1` allows replacing cloud data that already exists. Dangerous. |

## Web (React + Vite)

| Variable | Default | Description |
|---|---|---|
| `VITE_API_URL` | empty | Leave empty: in development Vite proxies `/api` to the local API, and in production the API serves the web app from the same origin. Set it only if the web app is hosted separately from the API. |

## Mobile (Expo)

| Variable | Default | Description |
|---|---|---|
| `EXPO_PUBLIC_API_URL` | `https://society-operations-suite.onrender.com` | API base URL. For local testing use the laptop's Wi-Fi address, for example `http://192.168.31.33:3001`. EAS builds take it from `mobile/eas.json`. |

## Generating secrets

```bash
# JWT_SECRET
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

## Checking that no secret is tracked by Git

```bash
git ls-files | grep -E '(^|/)\.env($|\.)' | grep -v example     # expected: web/.env.development only
git grep -nE 'postgres(ql)?://[^ ]*:[^ ]*@[^ ]*neon' -- . ':!*.example' || echo "no Neon URLs tracked"
```
